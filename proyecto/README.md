# Jorgharness

Un harness mínimo en Python que envuelve a un modelo de lenguaje y le da herramientas y contexto. Este README es un work in progress que irá mejorando a lo largo del curso.

Hola, Jorge del futuro. Este es el README del proyecto de aprendizaje de IA. ¿Qué vamos a construir? La idea es crear nuestro propio harness, que envuelva a un modelo de lenguaje y le permita interactuar con herramientas.

## Por qué lo construyo

La razón por la que iniciamos este proyecto es entender, a través de la creación de un harness, cómo funciona y qué partes lo componen. En un futuro se puede crear un harness propio para Grupo Alquila, o simplemente utilizar los conocimientos para mejorar el trabajo propio con las herramientas de IA a mi alcance.

El objetivo es crear un harness mínimo funcional, que tenga acceso a herramientas y a un contexto diseñado por mí mismo.

## Qué tendrá al final

- Un system prompt del harness.
- Un sistema para aprobar o rechazar las peticiones del modelo.
- Un sistema que ejecuta las instrucciones del modelo.
- Un sistema de loop que permita al modelo trabajar en tareas que requieren varios pasos o iteraciones.
- Elementos que ayudan al usuario a utilizar el modelo de manera más eficiente: modos de personalización desde la UX, herramientas de visualización que permitan entender qué hace el modelo, visualización de archivos clave, y elementos visuales que permitan identificar o cambiar cosas.
